01

Backpack

Top of Manifest 07's priority queue — unblocks the equip-visual loop, the one gear item currently in progress.

Reference size~50cm H × 32cm W × 17cm D
Tri budget500–1,200
DestinationContent/ZS/Items/Containers/
SocketSocketBack — confirm it exists on SKEL_TFA_Mannequin first
Naming outSM_Backpack / T_Backpack_BaseColor / MI_Backpack
Stage 1 — Blockout

  1. ReferenceSet scene units to meters. Import or rough in a simple capsule at 1.8m tall so you have a body to check proportions against — the bag should sit roughly between shoulder blades and waist.

  2. Main bodyAdd a Cube, scale to ~0.50m × 0.32m × 0.17m (H×W×D), apply scale (Ctrl+A). This is the pack's core volume.

  3. Soften edgesCtrl+B to bevel the vertical edges, small width (~1cm), 2 segments — reads as fabric, not a cardboard box, without spending real poly count.

  4. Front pouchDuplicate a smaller cube (~0.20m × 0.28m × 0.08m), position flush against the front face with a slight overlap so there's no visible gap, bevel to match.

Stage 2 — Details

  1. Compression strapsTwo thin flattened cubes (~2cm thick) wrapping partway around each side. Keep them flat rectangles — a slight bow isn't worth the poly cost at this budget.

  2. Shoulder strapsAdd a Bezier curve for each strap's path, set Bevel Depth to ~1.5cm in the curve's Object Data properties, then Convert To → Mesh once the shape reads right.

  3. Carry handleA short bent cylinder or partial torus above the main body, sized to a hand-width loop (~10cm).

  4. Zipper linesDon't model teeth. Mark a thin edge loop where a zipper would run, Ctrl+I (inset) a hair's width, small bevel — reads correctly at top-down gameplay distance per the project's own animation/art scope rule.

Stage 3 — Finish

  1. Merge & budget-checkCtrl+J everything into one object. Open the Statistics overlay and confirm you're inside 500–1,200 tris — if over, Decimate (Planar) the rounded sections or dissolve unneeded loops rather than cutting a real feature.

  2. Origin placementPlace the 3D cursor at the point that should align with SocketBack (roughly spine-height, back-center), then Object → Set Origin → Origin to 3D Cursor. This is critical — a worn mesh has no per-item code offset, so a wrong origin means a floating or clipped backpack in-game with no fix except remodeling.

  3. UV unwrapMark seams along hidden edges (bottom, strap undersides), Smart UV Project or hand-unwrap, pack islands into one 256×256 UV space.

  4. Texture & materialPaint or bake a single BaseColor (canvas fabric tone, darker AO in creases, a distinct tone for straps/hardware). One Principled BSDF: BaseColor texture plugged in, Roughness ~0.7 flat, Metallic 0.

Stage 4 — Export

  1. Apply transformsCtrl+A → All Transforms, one last time, before export.

  2. FBX exportSelected object only. Forward -Z, Up Y, Scale 1.00, Apply Scalings: FBX All. No armature/animation — this is a static prop.

  3. Import to UnrealInto Content/ZS/Items/Containers/. Rename the imported asset SM_Backpack, texture T_Backpack_BaseColor, create MI_Backpack off the shared item master material.

Duffle reuses this exact socket and topology approach once Backpack is done — Manifest 07 has it deliberately queued right after, sharing the base shape at a different scale/texture.
02

Residential Building — Test Blockout

Deliberately not final art — the dev chose "quick blockout, defer the real kit" (Manifest 05's B2-T2 decision stays open). This exists purely to test the multi-level/interior-visibility systems and loot placement on the most-repeated building type in the game.

Footprint~10m × 8m
Floor height~3m floor-to-floor (2 stories)
Wall thickness~0.2m
DestinationContent/ZS/Environments/_Blockout/House01/ (underscore prefix, kept separate from final content)
NamingSM_BLOCKOUT_House01_<Part> — never SM_House01_, so it can't be mistaken for finished content
Stage 1 — Ground floor shell

  1. SnappingEnable increment snapping (Shift+Tab, or the magnet icon) at 0.5m or 1m — speed matters more than precision for a blockout.

  2. Floor slabAdd a Cube, scale to 10m × 8m × 0.2m. This is Floor01 — keep it a separate object from everything else.

  3. Four wallsBuild front/back walls (10m × 0.2m × 3m) and side walls (0.2m × 8m × 3m) as four separate cube objects, positioned flush to the floor slab's edges. Separate objects, not one merged shell — this is what makes swapping in real kit pieces later a one-for-one replacement instead of a rebuild.

  4. Ceiling / second-floor slabDuplicate the floor slab, move up to 3m. This doubles as Floor01's ceiling and Floor02's floor.

Stage 2 — Openings

  1. Door cutoutAdd a cube sized ~1m × 0.3m × 2.1m where the front door goes, positioned to punch through the wall. Add a Boolean modifier (Difference) on the wall, target the door cube, apply, then delete the cutter cube.

  2. Window cutoutsSame Boolean approach, cube ~1.2m × 0.3m × 1.2m, sill height ~0.9m off the floor. Repeat per wall as needed — 2–3 windows per floor is enough for a blockout.

  3. Second storyRepeat Stages 1–2 offset up by 3m for Floor02's walls and openings.

Stage 3 — Vertical traversal & roof

  1. StairsA stepped row of small cubes (~0.25m tread depth, ~0.18m rise) connecting Floor01 to Floor02 — functional, not pretty. This is what actually exercises UZSElevationSubsystem's floor-detection and the aim-ray floor-plane resolve, so don't skip it even in a rough pass.

  2. RoofOne more flat slab above Floor02, or a simple two-plane pitched roof if you want the silhouette read from outside — not load-bearing for the system test, purely visual.

Stage 4 — Export & import

  1. Apply transformsOn every object, Ctrl+A → All Transforms.

  2. ExportEither export all pieces together (fastest for a one-off test level) or individually if you want to reuse a wall/floor piece elsewhere. Same FBX settings as the Backpack guide above — verify against the cube test first.

  3. CollisionOn import, make sure "Generate Missing Collision" is enabled (or add Box Simplified Collision manually in the Static Mesh Editor) — these need to be walkable and blocking, not just visual.

  4. Import locationContent/ZS/Environments/_Blockout/House01/ — deliberately outside the real environment folder structure Manifest 05 will eventually use, so nobody mistakes this for finished content later.
