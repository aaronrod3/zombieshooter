Per-Item & Per-Interaction Animation Matrix

Scope rule already locked (AnimationPlan_2026-08-07): a clip earns inclusion only if readable at top-down cam distance or gates gameplay timing. Weapons share clips by category, not one-per-weapon — MountedLongGuns (Handedness=TwoHanded) all ride the same rifle-class set; the multi-config rule means a new weapon in an existing category is a data-asset assignment, not a new animation.

Audio

All of it is Tier 9 (Manifest 02) by design — noise-as-threat is a pillar, but full production only starts once the systems it dramatizes are proven. Listed here so nothing gets forgotten when that tier opens.

CategoryContents
Zombie vocalizationPer-state set (idle/alert/chase/attack/death), per-config voice assignment, layered crowd/horde audio, distance/occlusion count-estimation

Body/healthCritical bleed cue, infection-stage audio, downed/revive stingers
UIMenu nav, inventory drag/drop, notification/toast, jam-warning
