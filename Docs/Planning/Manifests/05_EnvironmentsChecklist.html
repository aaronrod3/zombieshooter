District Build Checklist

Every building, room, and world prop the map needs, grouped by Grayback County's four districts (Manifest 01 §02) plus the hub compound. Zero content is currently owned in this category.

SourceEnvironmentCatalog_2026-08-29.md
Dated2026-09-06
Build tierManifest 02, Tier 6
Blocking everything below

B2-T2 — modular kit selection hasn't happened yet. Not a modeling task, a decision: pick or purchase the architectural kit before building a single room in bulk. Every checklist item on this page is inventory to build against that kit, not a queue to start today.

01

Hub Compound — Grayback Lodge

Small footprint, highest priority — seen every session, and a rough pass tests the vendor/stash loop end to end without the rest of the map existing.

Priority 1

The Lodge

Vendor NPC + contract board. Taxidermy/gun-rack decor as armory backdrop — worth prioritizing over generic dressing.

Priority 1

The Cache

Stash vault. Root-cellar / walk-in-cooler aesthetic, distinct shelving/storage furniture from the Lodge.

Priority 2

The Motor Barn

Vehicle storage — needs vehicle meshes as a dependency (Tier 8), don't block the barn shell on that.

Priority 3

Ridge Lookout Tower

Flavor only, no scoped gameplay purpose yet — don't over-invest here.

Satellite safe spots — new this session

Fire Watch Tower — Grayback Highlands St. Anne's Parish — Cedar Hollow edge County Line Truck Stop — Anders River Farmland Checkpoint Delta — Millbrook approach (hostile-held at start)

03

Modular Architectural Kit

The actual B2-T2 purchase/build target — every district above is assembled from this set.

Walls — exterior/interior, ≥1 damaged/breached variant Floors/ceilings — matched to interior-visibility technique Doors — intact, breachable, locked Windows — intact + broken Stairs — real geometry, multi-level Fences/chain-link — urban vs. rural variants Basements — fixed/hand-authored, own smaller kit (concrete walls, pillars, pipes)

Priority Build Order

  1. Land the B2-T2 kit-selection decision — nothing below starts in bulk until this happens.
  2. Grayback Lodge rough pass (Lodge + Cache specifically) — tests the vendor/stash loop end to end.
  3. Raid-zone buildings by district, mechanical-identity sites first (medical/firearms/food) before residential variety.
  4. Satellite safe spots (Fire Watch Tower, St. Anne's, County Line, Checkpoint Delta) — small footprint, high narrative payoff.
  5. Furniture, following whichever buildings land first.
  6. Exterior world props — pure dressing, last.
