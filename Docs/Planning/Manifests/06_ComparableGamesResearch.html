Field Study — Extraction Survival

Ten comparable games, read for hub systems, objective structure, exfil mechanics, loot economy, and how each delivers a hidden narrative. What to steal, and what to build around instead of repeating.

Games covered10, ranked by depth of relevance

01

Primary Deep Dives

Escape from Tarkov Hard extraction

HubSingle hideout, ~20 upgradable modules gated on items/roubles/trader loyalty/skills. No combat here — pure crafting/passive income/storage.
Objectives7 traders, strict tiered questlines — kill/fetch/place-in-raid, gate gear behind loyalty level.
ExfilHard extraction points per map, some keyed/timed. Failed or late extract loses the raid.
DeathLose everything but melee/compass/armband/secure container. Full wipe every ~6–7 months.
LootTiered rarity, container-type-driven, finite per-raid, restocks on server restart.
NarrativeTerraGroup's real activity is the unstated mystery — 32 optional "Evidence" collectibles, quest text, NPC dialogue.
The hookReal loss makes every raid decision matter — gear fear and the gear-up→raid→extract-or-lose loop is the addictive core.

Project Zomboid Freeform sandbox

HubNone designed — players build their own base anywhere via Carpentry.
ObjectivesNone. Survival itself is the objective.
ExfilNone — one continuous persistent world, no session boundary.
DeathFull permadeath, no respawn on survival presets.
LootSandbox-tunable rarity multipliers, pre-looted buildings, diminishing over time.
NarrativeNear-none — purely environmental implication.
The hook"Your death is inevitable" — the fun is how creatively/long you delay it. No boss, no ending.

DayZ Emergent PvP

HubNone official — improvised camps/tents/stashes, vulnerable to raiding.
ObjectivesNone in vanilla — fully freeform.
ExfilNone — persistent, always-on world.
DeathLose everything; corpse recoverable only before the server's item-lifetime timer despawns it.
LootCentral Loot Economy — server-wide caps, auto-cleanup, often tuned too scarce.
NarrativeDeliberately unexplained — devs never confirm outbreak origin.
The hookEvery encounter is a real stranger who might help or kill you — the "will they shoot" moment is the entire game.

SCUM Simulation depth

HubFour safe-zone trading posts (Fame Points economy) + player-built bases anywhere.
ObjectivesTrader "Life Goals" mission chains, added only in the 1.0 release (June 2025).
ExfilNone — Bunkers are raid-in-place high-value zones, not extraction points.
DeathFame score drops; full loss tied to the BCU-2 neural implant vitals system.
LootBunkers/named POIs hold top-tier gear, hand-placed.
NarrativeReality-TV frame (TEC1 broadcasts prisoners) — found audio logs, implant lore.
The hookSimulation depth as spectacle — also its most-criticized trait (see pitfalls).

04

Patterns Worth Stealing

1

Optional lore collectibles kept separate from critical-path quests (Tarkov's Evidence, STALKER 2's PDAs) — the mystery stays genuinely optional.

2

A contract-board with one "current assignment" + freeform overflow (DRG) — avoids Tarkov's "everything gated behind quest RNG" complaint.

3

Durability-banded malfunction thresholds (Tarkov's 93%/5% jam breakpoints) — directly reusable against the existing ConditionQuality-driven jam system.

4

A corpse-run recovery window (DayZ) — softens permadeath since dropped loot already persists; make the race-back tension explicit.

5

Config-driven rarity per container archetype (Zomboid, Tarkov) — matches the existing RollConditionQuality pattern already in code.

6

Idle/automated base tasks while offline (Once Human's Deviants) — a hub-return hook that doesn't require combat.

7

Trader opening hours + rotating stock (7 Days to Die) — ties hub visits to the existing day/night clock instead of an always-open menu.

8

Soft-into-hard extraction hybrid (Division's Dark Zone) — borrow the tension, not the ceremony, for the mixed-exfil model.

9

Clue-chain objective structure (Hunt: Showdown) — good template for the "recon" contract type.

10

A weekly-rotating escalating challenge run (DRG Deep Dives) — a retention lever once the core loop is proven, not before.

11

Rescue-instead-of-silent-deletion as a designed-in safety valve (Icarus), not a reactive patch — build this into the drop-off model now.

12

Implant/vitals-as-worldbuilding (SCUM's BCU-2) — a diegetic reason for the needs/moodle HUD, worth considering for how it's justified in-fiction.

05

Pitfalls to Avoid

✕

Tarkov's wipe fatigue — full resets every 6–7 months. Permadeath already provides per-character loss tension; don't add a parallel full-world-wipe layer without a clear reason.

✕

DayZ's loot scarcity spiral — over-tuned rarity reads as "a running simulator with flashes of disappointment." Tune finite loot generously for the first hour.

✕

DayZ's KOS culture — lower risk here since this is co-op-first, but any future PvP/hostile system should avoid pure win-by-killing-other-survivors incentives.

✕

SCUM's simulation bloat — an entire stat page called "needlessly complicated." The existing needs/wound/infection stack is already approaching this ceiling — don't out-simulate what the UI can legibly show.

✕

STALKER 2's over-promised emergence — marketed "A-Life 2.0" as fully living, shipped something that read as scripted. Describe the spawn-director accurately; don't oversell it as emergent.

✕

Icarus's permadeath support disaster — harsh timer-based loss players triggered by accident forced an emergency rescue patch. Build the forgiving failure mode into the contract drop-off model from day one, not after complaints.

✕

Sons of the Forest's disconnected narrative — survival mechanics and story built independently read as "two games stapled together." Integrate mystery discovery with existing looting/traversal (the PDA model), not a separate quest-log track.

✕

7 Days to Die's "horde always finds you" — Blood Moon zombies ignore stealth entirely, which reads as removing player agency. If migrating hordes are meant to be avoidable, make positioning visibly matter.
