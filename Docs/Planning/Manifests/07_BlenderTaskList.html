01

Project-Wide Conventions

NamingMesh SM_<Name> (or SM_<Abbrev>_<Part> multi-part); texture T_<Name>_BaseColor; material M_<Name> (master) / MI_<Name> (instance). ZS prefix applies to classes/BP/DA/WBP only, never raw art.
Export (unverified)Blender FBX, Forward -Z, Up Y, Scale 1.00, Apply Scale FBX All. Apply all object transforms (Ctrl+A → All Transforms) before export.
Origin placementCritical for WornMesh items — must sit correctly relative to its character socket, no per-item code offset exists. WorldMesh pickups are less strict.
CollisionWornMesh and weapon-attachment meshes get NoCollision forced automatically at runtime — no manual setup needed. WorldMesh pickups can keep simple auto-collision or none.
Texture / materialOne shared master M_ZS_Item (not created yet) + one MI_<ItemName> instance per item, not an atlas. BaseColor only by default; Roughness/Metallic as flat scalars unless an item genuinely mixes materials. 256×256 default, 128×128 for small clutter.
Scale referenceModel at real-world scale in Blender meters. Not the same as UZSItemConfig::ItemSize (gameplay compartment-fit, unrelated to physical dimension).
Icon pipelineBP_IconGenerator/M_Icon exist mid-edit — appears to be a render-capture-to-icon system. Unconfirmed — if true, no separate 2D icon art is ever needed. Confirm before assuming.

Folder structure — revised 2026-09-07 (full weapon roster expansion)

Superseded the old flat Weapons/{Ammo,Melee,Pistol,Rifle}/ layout — it doesn't scale to 3–6 weapons per category. Each weapon now gets its own subfolder (mesh+texture+material+DA+BP together), matching the pattern the FAB pack's own mesh dump already uses.

Content/ZS/Items/ ├── Weapons/ │ ├── Rifles/<Name>/ (5 — Mk18, AKM, R-36, M16, Mk16) │ ├── Pistols/<Name>/ (3 — P80, R-357, MP-9) │ ├── Shotguns/<Name>/ (3 — M1014, M870, Sawed-Off 12) │ ├── SMGs/<Name>/ (4 — SMG-5, SMG-7, PP-9, SMG-3) │ ├── LMGs/<Name>/ (4 — M249, M134, RPK, M1A1) │ ├── HeavyWeapons/<Name>/ (2 — M320, RPG-7) │ ├── Melee/<Name>/ (unchanged — Bat, Nailed Bat, Knife, Machete) │ ├── Ammo/Ammo_<Caliber>/ (10 calibers, see Weapon Roster table below) │ └── _SourceMeshes/LowPolyWeapons/ (was LowPolyPackUsedMeshes — unchanged, raw FAB reference pool) ├── CombatTactical/{Grenades,Explosives}/ ├── Medical/{Bleeding,Infection,Fracture,PainManagement,Emergency}/ ├── Food/ (unchanged, flat, placeholders) ├── Comms/Radio/ (new) └── Containers/, Tools/, ItemDataAssets/, IconCreator/ (unchanged)
MigrationExisting Weapons/Pistol/ → Pistols/<name>/ and Weapons/Rifle/ → Rifles/Mk18/ must be done via the Content Browser's Move/Rename — never a raw filesystem move, it breaks every reference into the asset.
RemovedContent/ZS/Weapons/ no longer exists — don't reference it if seen in an older doc
TriggerFinal assets bake the trigger into BaseWeaponMesh permanently — leave UZSWeaponConfig::TriggerMesh unset on every new weapon. No code change needed.

AKM/RPK residual risk: both are real designations, but the letters themselves carry the Kalashnikov association — the only way around that is dropping to an obscure Soviet GRAU index number (e.g. 6P1) instead. Left as AKM/RPK per instruction; revisit if that changes.

21 weapons, 10 ammo types — most weapons share a caliber. Per caliber, build in priority order: Loose Round (bullet+case combined — the actual loot/pickup representation, build first) → Case (ejected-shell VFX, nice-to-have) → Bullet-only (lowest priority). Calibers: 5.56×45 (Mk 18, R-36, M16, Mk 16, M249 — 5 weapons), 9×19 (P80, MP-9, SMG-5, PP-9, SMG-3 — 5 weapons), 7.62×39 (AKM, RPK — 2 weapons), 12 Gauge (M1014, M870, Sawed-Off 12 — 3 weapons), plus one weapon each on 7.62×51 (M134), .357 Mag (R-357), 4.6×30 (SMG-7), .45 ACP (M1A1), 40mm Grenade (M320), RPG Rocket (RPG-7).

Active Priority Queue

Work top to bottom — each unblocks a mechanic that's otherwise untestable, ahead of anything that just adds variety.

  1. Backpack in progress · 500–1,200 tris · Content/ZS/Items/Containers/
  2. Pistol Magazine ~150 tris · mechanical blocker, no reload without it
  3. SMG Magazine ~150 tris · mechanical blocker
  4. Helmet 300–800 tris
  5. Vest 500–1,200 tris
  6. Belt 300–800 tris
  7. Splint real gap — Disinfectant/Splint archetypes coded, no real item exercises them
  8. Wrapped Snack / Candy Bar confirmed real gap, no pack match
  9. Machete the one true melee gap after the plausible-match tier is confirmed

Zombie mesh + skin remains the single biggest content gap overall, but runs as a parallel track, not part of this queue — it's a rigged/skinned character + animation retarget, a different pipeline than a static prop. Pursue via sourcing a pack alongside the queue above, don't block either on the other.
