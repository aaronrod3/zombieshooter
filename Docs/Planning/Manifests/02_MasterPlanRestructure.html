01

Why This Rebuild

The existing Docs/Beta/ plan (00_MasterPlan.md + 20 phase files) is thorough and not wrong — B0's stabilization debt is real, the item-instance refactor was the right call, and most phase-internal task breakdowns below are lifted straight from it. What it isn't is fast to orient from: 20 files, a contradiction register with 14 entries, ~70 open questions, and a session estimate of 195–250 (10–14 months part-time) that bundles "get a fun loop working" together with store pages, localization, and screen-reader support at the same priority level.

This manifest is a priority lens on top of that plan, not a replacement for it. Every tier below maps to specific existing phases (B0, B1, BH…) — go to those files for the actual task-by-task detail. What changes here: the sequencing is collapsed into one linear track instead of a two-stage/three-branch dependency graph, everything not required to reach a playable internal beta is explicitly pushed past it, and the three decisions from this session are threaded through wherever they touch existing scope.

02

Three New Decisions, Applied

Resolved this session. Each one lands as a concrete scope change against specific existing phase files — not just a philosophy shift.

World layout → Hub + satellite safe spots

Grayback Lodge stays the one true bank (Cache = the only place that permanently secures loot). New: four satellite locations (Fire Watch Tower, St. Anne's Parish, County Line Truck Stop, Checkpoint Delta — see Manifest 01 §5) offer rest and light trade only, no stash access. New task: BH-T7 Satellite Safe Spots — placement, claim/discovery state, and the rest-only interaction, sized S, sequenced in Tier 6 alongside region content since it's physically built the same way as any other POI.

Exfil model → Mixed, resolves OQ-BR-04

AZSExtractionPointActor/Server_RequestExtraction are repurposed, not deleted. General loot needs no ceremony — walk or drive it to the Cache and deposit, an ordinary container interaction. Contract-critical items (samples, escort targets) additionally require reaching that specific contract's drop-off, which reuses the extraction-point actor as a "delivery point" rather than a raid-wide extraction mechanic. OQ-BR-02's channel-time question re-activates, scoped only to contract drop-offs. Lands as part of BH-T3 (contract system), not a separate phase.

Objectives → Hybrid freeform + contracts

Mostly already the plan's shape — it just needs the seam cleaned up. B5 owns freeform: the event director, radio, and the investigation/mystery arc, now executed directly against Manifest 01's full lore bible instead of "brainstorm live" (OQ-B5-01 is hereby resolved). BH-T3 owns contracts: vendor-given, optional, better payout. Neither blocks the other — a player can finish the game without accepting a single contract.

★

Internal Beta Gate

Milestone, not a phase

This is the "at least get a beta done" target. Everything in Tiers 0–8 is exactly what's needed to hand this to 6–12 testers for a real session — nothing more. Full checklist: Docs/Beta/99_DefinitionOfBetaReady.md Gate 1.

Reaching this gate is the finish line this rebuild optimizes for. Tiers 9+ below make the game public-shippable, not more playable — don't let them creep earlier.
